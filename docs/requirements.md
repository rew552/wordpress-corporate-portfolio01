# 要件定義

## 目的と対象
WordPress案件への応募時に、標準機能で企業サイトを設計・実装し、非エンジニアが更新できることを示す。地域の中小企業の広報担当者と、取引を検討する閲覧者を想定する。

## 架空企業・コンセプト
「余白ワークス株式会社」。業務整理、デジタル導入、運用定着を支援する架空企業。「仕事を整える。可能性が、広がる。」をメッセージとする。実在顧客、実績数、個人情報は使用しない。全ページのフッターとREADMEで自主制作を明示する。

## IA
主導線：TOP → サービス → お問い合わせ。理解導線：TOP → 私たちについて → 会社概要。更新導線：TOP → お知らせ一覧 → 詳細。補助導線：フッター → 資料 / プライバシー / デモ管理画面。資料 → 保護ページ。採用は事業コンセプトに不要なため追加しない。

## 受け入れ条件
- 必須ページ、404、検索、分類一覧が表示され、ナビとフッターで移動できる。
- 標準投稿・カテゴリ・アイキャッチでお知らせを管理できる。
- TOPを含む固定ページをGutenbergで編集・保存し、公開画面に反映できる。
- メディア画像を標準UIで置換できる。
- フォームは必須・メール形式・10文字以上・同意を検証し、完了を表示。入力データを保存・送信しない。
- PDFを開ける。保護ページは認証前に本文を表示しない。
- 375px / 390px / 768px / 1440pxで横スクロールなく閲覧できる。
- 意味のある見出し、ランドマーク、入力ラベル、キーボードフォーカスがある。
- Blueprintで第三者が初期状態を再現できる。

## 制約・スコープ外
WordPress本体は含めない。VPS / EC2 / GitHub Pagesは不要。Block Theme / theme.json / Gutenberg / Playgroundを使用。不要なCPT、Headless、外部API、SMTP、解析サービスは追加しない。実在企業への納品、実際の問い合わせ受付、決済、会員登録、厳密な機密情報のアクセス制御は対象外。
